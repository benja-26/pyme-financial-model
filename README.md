# pyme-financial-model
Modelo financiero integral para PyMEs. Incluye proyección de ingresos/egresos, flujo de fondos, estado de resultados, análisis de rentabilidad, punto de equilibrio, KPIs y escenarios. Diseñado para consultoras, estudios contables y empresas que buscan tomar decisiones basadas en datos financieros reales.
# 📊 Modelo Financiero para PyMEs

> Herramienta de planificación y control financiero diseñada para 
> pequeñas y medianas empresas. Desarrollada con estándares de 
> consultoría financiera profesional.

## ¿Qué incluye?
- Proyección de ingresos y egresos a 12 meses
- Flujo de fondos mensual
- Estado de resultados proyectado
- Punto de equilibrio dinámico
- Análisis de escenarios (optimista / realista / pesimista)
- KPIs financieros con semáforos visuales
- Dashboard ejecutivo

## ¿Para quién es?
- Dueños de PyMEs que quieren controlar su negocio
- Contadores y consultores que asesoran empresas
- Emprendedores en etapa de planificación

## Cómo usar el modelo
1. Descargar el archivo `pyme_financial_model_template.xlsx`
2. Completar la hoja `PARÁMETROS` con los datos de tu empresa
3. Cargar el plan de ventas en la hoja `INGRESOS`
4. Ingresar estructura de costos en `COSTOS Y GASTOS`
5. El modelo calcula todo automáticamente
